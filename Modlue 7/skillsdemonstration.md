What are 3 examples of problems that are in NP? Please be as descriptive as possible in describing these problems.
1. Sudoku
Sudoku is a puzzle where you fill a grid with numbers from 1 to 9. Each row, column, and 3×3 box must contain every number from 1 to 9 without repeating.
Finding the correct numbers can be difficult, but checking whether a completed puzzle is correct is much easier.
2. Traveling Salesperson Problem
This problem involves a salesperson who needs to visit multiple cities and return to where they started. The goal is to find the shortest possible route. This can be difficult because there are many different routes to choose from, especially when more cities are added but if you ask the salesperson their route itd be quicker.
3. Subset Sum
This problem gives you a list of numbers and a target number. You have to figure out whether some of the numbers in the list add up to that target.

What is the difference between universality, computability, and intractability, in your own words.
Universality - computer can perform diff tasks as long as its given the proper instructions
Computability - can a problem be solved by an algorithm
Intractability - When a problem can be solved, but finding the solution takes too much time or too many resources, especially as the problem gets bigger.
